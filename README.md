## 🎯 À propos du projet

Ce **dashboard interactif** propose une analyse scientifique et comparative de **6 livres sacrés majeurs** de l'humanité : la **Torah**, la **Bible**, le **Coran**, les **Vedas**, le **Tripitaka** et l'**Avesta**.

Le projet combine :

- 📊 **Analyse quantitative** (stylométrie, TTR, statistiques)
- 🔤 **Analyse linguistique** (racines, morphologie, familles)
- ⏳ **Analyse historique** (chronologies, manuscrits, contextes)
- 🌍 **Analyse géographique** (aires culturelles, routes commerciales)
- 🎨 **Design moderne** aux couleurs tricolores Bleu-Blanc-Rouge

> **Objectif** : Offrir un outil pédagogique et scientifique **libre, gratuit et multilingue** pour étudiants, chercheurs et curieux.

## 🚀 Installation rapide

### 📦 Option 1 : Utilisation directe (recommandé)

Aucune installation requise ! Il suffit de cloner et d'ouvrir :

```bash
git clone https://github.com/username/sacred-books-dashboard.git
cd sacred-books-dashboard
open index.html
```

### 🐍 Option 2 : Version Streamlit (Python)

```bash
git clone https://github.com/username/sacred-books-dashboard.git
cd sacred-books-dashboard

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run dashboard_livres_sacres_scientifique_avance.py
```

### 🐳 Option 3 : Docker

```bash
docker build -t sacred-books-dashboard .
docker run -p 8501:8501 sacred-books-dashboard
```

### 📋 Prérequis

| Outil | Version minimale | Recommandée |
|---|---|---|
| Navigateur | Chrome 90+ / Firefox 88+ / Safari 14+ | Dernière version |
| Python | 3.9+ | 3.11+ |
| Node.js (dev) | 16+ | 20+ |

### 📈 Métriques analysées

- **Textuelles** : versets, mots uniques, chapitres, complexité

- **Thématiques** : monothéisme, prophètes, loi, salut, révélation
- **Géographiques** : régions, centres culturels, routes commerciales

## ♿ Accessibilité

Ce projet respecte les **WCAG 2.1 niveau AA** :

- ✅ **Navigation clavier** complète (Tab, Enter, Échap)
- ✅ **`aria-label`** sur tous les boutons interactifs
- ✅ **Contrastes** ≥ 4.5:1 (textes normaux), ≥ 3:1 (grands textes)
- ✅ **`prefers-reduced-motion`** respecté
- ✅ **Focus visible** (outline rouge)
- ✅ **Sémantique HTML5** (main, nav, section, article)
- ✅ **Alt text** sur toutes les images
- ✅ **RTL** pour arabe et hébreu
